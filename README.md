# Hello Data World

This is my first data project in the Full-Stack Data/ML roadmap.

## Goal
To set up a professional development environment and create a simple Python script that uses Pandas to analyze a small dataset.

## Tools Used
- **OS:** Ubuntu (WSL2)
- **Language:** Python 3.14
- **Library:** Pandas
- **Version Control:** Git & GitHub (SSH)
- **Environment:** Virtual Environment (venv)

## How to Run

1. Clone the repository:
   ~~~bash
   git clone git@github.com:Official-Sinario-Saz/hello-data-world.git
   ~~~

2. Navigate to the project directory:
   ~~~bash
   cd hello-data-world
   ~~~

3. Create a virtual environment:
   ~~~bash
   python3 -m venv venv
   ~~~

4. Activate the virtual environment:
   ~~~bash
   source venv/bin/activate
   ~~~

5. Install dependencies:
   ~~~bash
   pip install -r requirements.txt
   ~~~

6. Run the script:
   ~~~bash
   python hello.py
   ~~~

## Output
The script prints a simple DataFrame and calculates the average age.
